Created 2026-09-24 at his request: *"Remember each one of these things we're
working on now and save it in a file so I can just ask to bring this up
instead of having to remember."*

`C:\kals-repo\OPEN_WORK.md` holds every running test with its bar and date,
the coin-race items, the decisions waiting on him, and what was decided and
closed. Each entry carries a **"Say: ..." handle** — e.g. "the fresh offer
test", "hourly BTC", "the edge floor test", "photo finishes", "earlier race
entry", "the tie fix", "the disk", "the VM", "size up", "the weather idea",
"the earthquake idea", "the control arms".

**Why:** he works across devices and cannot hold a dozen test names; without
it he has to re-derive the state from HANDOFF every time.

**How to apply:** when a test's state changes (an arm starts, a bar is met, a
flag goes live, an idea dies), edit OPEN_WORK.md in the same commit — a stale
index is worse than none. Read it in the first reply of a new session
alongside CURRENT_STATE.md. See [[next-session-first-jobs]],
[[handoff-is-the-only-continuity]].
