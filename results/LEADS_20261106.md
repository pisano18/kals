## L1. Has `taker_outcome_side` ever been missing? (F-I04 x F-I06)

- **F-I04** -- Every trade record carries `taker_outcome_side` -- WHO crossed, on which side, to the millisecond.
- **F-I06** -- Kalshi renamed fields once and 68,976,084 of 68,976,084 deltas went unparsed while every stage exited 0.

**The measurement.** One streaming pass over the `trade` channel: per UTC hour, (a) records read, (b) how many carry `taker_outcome_side` present and non-null, (c) the distinct value set that hour. Output is a list of hours where (b)/(a) < 100%, with raw counts. That is a coverage count, not an effect estimate, so hard rule 4 does not bite -- but report hours, never markets, and say so.

**Why it is worth a pass.** 21 research files read this field, `v-tradefeed` logs from it live, the `arm-toxic` gate decides on it, and F-P10's "takers at the touch carry ZERO information (t=0.2)" rests on it entirely. A window where the field was absent or constant turns that t=0.2 into a null from an estimator that could not have found anything -- uninterpretable by this repo's own rule. Nothing has checked. `doctor.py` samples 4,000 messages per channel and is not time-stratified: it catches a rename happening now, not a hole in the past. `competitors.py` reports torn files, missing hours and thin hours, but never field presence.

**What would make it an artefact.** Three things, each of which looks exactly like a rename: a torn gzip hour, where the standard reader returns ZERO lines rather than half (F-I05) -- so the denominator must come from a reader using `gzsalvage`; a silently skipped ticker (F-I07), which reads as zero records rather than an error; and a legitimately quiet hour, where one malformed record is a large percentage -- so set a minimum denominator and print counts beside every rate.

**Power.** At ~153k records an hour (57.7M over 376 h, F-I03), any hour with >=1,000 records resolves a shortfall of >=0.3%, and a whole missing hour is certain. So "no hours missing" would be a real null, not no power.

**Cost.** Cheap. One pass over the `trade` channel only -- no `load_quotes`, no 2-3 GB resident, no replay. Minutes, not hours, and the recorders are untouched.
